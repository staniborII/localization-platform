# 0004. CloudFront in front of function URLs

## Status

Accepted

## Context

The web client is a static Next.js export. It needs two calls: a presigned upload URL, and job status. The web client then uploads the MP4 straight to S3. Authentication is not part of this version. A later login would be a JWT check, not a reason to run a container.

## Decision

CloudFront serves the private site bucket and forwards `/api/uploads` and `/api/jobs*` to two Lambda function URLs. The function URLs require IAM. CloudFront signs those calls with origin access control. Each function allows this distribution both `lambda:InvokeFunctionUrl` and `lambda:InvokeFunction`. The API behaviors forward the viewer headers except Host, and they leave compression off, so the request CloudFront signs is the request the function URL checks. The browser sends the POST body hash in `x-amz-content-sha256`, and that header travels with the other viewer headers. The site and the API share one hostname, so the browser does not make a cross-origin API call. Job status is polled. Playback uses a presigned GET that expires in 15 minutes.

## Alternatives

- API Gateway. It adds a gateway fee, request validation, and a JWT authorizer. This web client has two routes and no login. The gateway can sit in front later without moving the functions.
- A Next.js server on Fargate. That is a running task, a load balancer, and a VPC. The pages do not need a server.
- WebSockets. A transcription takes minutes. A two-second poll does not change when the subtitles appear.

## Trade-off

Anyone who can open the CloudFront hostname can upload, until a user pool is added. The default certificate cannot enforce TLS 1.2 as its minimum. Viewer HTTP still redirects to HTTPS. A custom domain and a web application firewall stay off while `deployCustomDomain` is false. There is no geo restriction.

## Cost

Function URLs have no gateway fee. CloudFront is priced per request and per GB. The default hostname has no monthly charge. The distribution uses price class 100. A web application firewall and a custom certificate stay off because each adds a standing charge.

## Failure

The web client shows the JSON error from the function. A local `next dev` server has no CloudFront in front of it, so the pages report that the API is not reachable. A failed upload does not start a job, because the job starts from the S3 event, not from the web client.
